# 📊 MLData Collector Plugin

**MLData Collector**는 마인크래프트 서버에서 일어나는 모든 주요 이벤트를 실시간으로 수집하여 **Supabase** 데이터베이스에 저장하는 강력한 데이터 분석 플러그인입니다. 서버 관리자는 수집된 데이터를 통해 유저의 행동 패턴, 이동 경로, 서버 내 경제 및 활동 현황을 시각적으로 파악할 수 있습니다.

---

## ✨ 주요 기능

*   **📍 완벽한 이동 경로 추적:** 3초 주기로 모든 플레이어의 X, Y, Z 좌표와 바라보는 방향(Yaw, Pitch)을 기록하여 이동 경로를 지도 형태로 분석할 수 있습니다.
*   **📦 세밀한 블록 및 아이템 추적:** 블록 설치/파괴뿐만 아니라 아이템 버리기/줍기, 상자 열기, 호퍼 전송 등의 정밀한 아이템 이동 흐름을 추적합니다.
*   **⚔️ 전투 및 데미지 기록:** 누가 누구에게(혹은 몬스터에게) 데미지를 입혔는지, 어떤 원인으로 사망했는지 정확히 기록합니다.
*   **💬 채팅 및 세션 관리:** 유저의 서버 접속/퇴장(IP 포함), 일반 채팅 및 명령어 사용 기록을 저장하여 서버 관리를 돕습니다.
*   **⚙️ 간편한 내장 웹서버:** 플러그인 자체에 가벼운 웹서버가 내장되어 있어 별도의 웹 호스팅 없이도 `http://서버아이피:8080`을 통해 즉시 데이터를 열람할 수 있습니다.

## 🚀 설치 및 설정 방법

1.  플러그인 `.jar` 파일을 서버의 `plugins/` 폴더에 넣고 서버를 구동합니다.
2.  `plugins/MLDataCollector/config.yml` 파일이 생성되면 다음 정보를 입력합니다:
    ```yaml
    # Supabase 프로젝트 URL
    supabase-url: "https://여러분의-주소.supabase.co"
    
    # Supabase Service Role Key (보안(RLS)을 위해 반드시 service_role 키를 사용하세요!)
    supabase-key: "여러분의-service-role-key"
    
    # 내장 웹서버 포트 (기본값: 8080)
    web-port: 8080
    ```
3.  플러그인을 리로드(`/reload`) 하거나 서버를 재시작합니다.

## 🔒 데이터베이스 보안 (필수)
수집된 데이터를 안전하게 보호하려면 Supabase에서 **RLS (Row Level Security)**를 반드시 활성화해야 합니다. 플러그인은 `service_role` 키를 사용하여 보안 장벽을 우회하여 데이터를 저장하며, 외부에서는 읽기 전용(`anon`)으로만 접근하도록 구성해야 합니다.
