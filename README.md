# 📊 ML Data Collector (Minecraft Plugin)

마인크래프트 서버의 방대한 데이터를 머신러닝 및 통계 목적으로 수집하고, 플러그인에 내장된 웹 서버를 통해 세련된 대시보드로 시각화하는 독립형 최적화 플러그인입니다.

## 🚀 주요 기능
1. **완벽한 비동기 하이브리드 저장**: 기본적으로 내장 로컬 DB(`SQLite`)를 사용하여 렉 없이 빠르게 데이터를 저장합니다. 필요할 경우 `config.yml` 설정 하나만으로 **Supabase(클라우드)**로 데이터를 쏴주는 클라우드 모드로 변신합니다.
2. **초경량 내장 웹 서버 및 SPA 대시보드**: 별도의 외부 웹서버 없이, 플러그인 자체 포트(기본 8080)로 최고급 수준의 로그인 화면과 데이터 표(Table)가 제공되는 SPA(Single Page Application)를 구동합니다.
3. **철저한 보안 (Token Auth)**: 못생긴 브라우저 알림창을 버리고, 자체 커스텀 로그인 페이지와 보안 토큰 발급 시스템을 적용하여 외부인의 접근을 차단합니다. (기본 비밀번호: `10313`)
4. **미니멀 프리미엄 UI**: 흔한 파란색/녹색 UI를 탈피하고, Vercel/Linear 등 최신 실리콘밸리 트렌드에 맞춘 칠흑 같은 다크 모드 글래스모피즘(투명 유리) UI를 제공합니다.

## 💻 인게임 명령어 가이드
(명령어 사용을 위해서는 `mldata.admin` 펄미션 또는 OP 권한이 필요합니다.)
* `/mldata status`: 플러그인의 현재 통신 상태와 서버 구동 여부를 확인합니다.
* `/mldata forcesync`: 메모리에 모여있는 모든 데이터를 즉시 DB에 강제 저장합니다.

## ⚙️ 설정 가이드 (`plugins/MLDataCollector/config.yml`)
```yaml
database:
  type: "sqlite" # 로컬 파일 저장은 sqlite, 클라우드 전송은 supabase
  supabase-url: "YOUR_SUPABASE_URL_HERE"
  supabase-key: "YOUR_SUPABASE_ANON_KEY_HERE"

web:
  port: 8080
  password: "10313" # 자체 로그인 페이지 접속 비밀번호
```

## ☁️ [선택] Supabase 사용자를 위한 SQL 설정 가이드
`config.yml`에서 `database.type`을 `supabase`로 설정하셨다면, 먼저 Supabase 웹 대시보드 좌측의 **SQL Editor**에 들어가 아래 코드를 복사/붙여넣기 후 1회 실행(Run)해주셔야 합니다.

```sql
CREATE TABLE IF NOT EXISTS server_metrics (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  tps REAL,
  ram_used_mb BIGINT,
  ram_max_mb BIGINT,
  loaded_chunks BIGINT,
  entity_count BIGINT,
  online_players BIGINT,
  timestamp BIGINT
);

CREATE TABLE IF NOT EXISTS player_movement (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  player_name TEXT,
  player_uuid TEXT,
  world TEXT,
  x REAL,
  y REAL,
  z REAL,
  yaw REAL,
  pitch REAL,
  timestamp BIGINT
);

CREATE TABLE IF NOT EXISTS block_events (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  action TEXT,
  player_name TEXT,
  block_type TEXT,
  world TEXT,
  x BIGINT,
  y BIGINT,
  z BIGINT,
  timestamp BIGINT
);

CREATE TABLE IF NOT EXISTS death_events (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  player_name TEXT,
  death_message TEXT,
  cause TEXT,
  world TEXT,
  x REAL,
  y REAL,
  z REAL,
  timestamp BIGINT
);

CREATE TABLE IF NOT EXISTS redstone_events (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  block_type TEXT,
  world TEXT,
  x BIGINT,
  y BIGINT,
  z BIGINT,
  old_current BIGINT,
  new_current BIGINT,
  timestamp BIGINT
);

CREATE TABLE IF NOT EXISTS interaction_events (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  player_name TEXT,
  target_type TEXT,
  target_name TEXT,
  action TEXT,
  world TEXT,
  x REAL,
  y REAL,
  z REAL,
  timestamp BIGINT
);

CREATE TABLE IF NOT EXISTS damage_events (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  attacker_name TEXT,
  victim_name TEXT,
  damage REAL,
  cause TEXT,
  world TEXT,
  x REAL,
  y REAL,
  z REAL,
  timestamp BIGINT
);
```
